# Branding sources

`resources/drawables/launcher_icon.svg` is the authoritative vector logo. The
PNG icons are deterministic exports made by `tools/export-assets`.

`hero-background-source.png` is the original generated, text-free source.
`hero-prompt.txt` records its exact prompt. `tools/export-assets` crops it and
adds the exact Aerobic Guard title and tagline to produce the store hero.
