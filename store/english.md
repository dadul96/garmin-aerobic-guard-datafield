# Aerobic Guard

Stay steady. Ride longer.

Aerobic Guard is a calm full-screen cycling data field for long aerobic and
endurance rides. It shows live power against a target range, heart rate against
a ceiling, advisory cadence guidance, cumulative carbs by now, speed, and
elapsed activity time. It is not a workout player, medical device, fueling
alert system, or FIT recorder.

Add Aerobic Guard to a one-field, full-screen data page. Smaller placements
display `FULL SCREEN REQUIRED`.

Supported: Edge 540 / 540 Solar, Edge 550, Edge 840 / 840 Solar, Edge 850,
Edge 1040 / 1040 Solar, and Edge 1050. Physical testing: Edge 840. Other
products require compiler and simulator validation before the beta is released.
