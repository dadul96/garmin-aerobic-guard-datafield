# Changelog

## 1.0.0

- Add full-screen power, heart-rate, cadence, cumulative carbohydrate, speed,
  and elapsed-time display for Edge 540, 550, 840, 850, 1040, and 1050.
- Add one-time Garmin cycling-zone/FTP target initialization, opinionated
  cadence and carbohydrate defaults, and on-device settings.
- Add a configurable 1-30 second displayed-power average, responsive layouts,
  touch and button keypad input, null-safe live state, and lifecycle resets.
- Add public documentation, privacy and support information, release assets,
  and isolated production packaging.
