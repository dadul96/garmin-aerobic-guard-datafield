# Aerobic Guard privacy

Aerobic Guard runs entirely on the Garmin device. It has no accounts,
networking, advertising, analytics, external data collection, or location
handling. It stores only the rider's Aerobic Guard preferences on device.

During an activity, it reads the live power, heart-rate, cadence, speed,
elapsed-time, and activity-average values Garmin supplies. These readings are
used transiently to draw the data field and are not retained by Aerobic Guard
after use or transmitted anywhere. Garmin's normal activity recording is
separate from Aerobic Guard.

The sole permission is User Profile. It is used only for the one-time cycling
power-zone/FTP and heart-rate-zone behavior described in the product contract,
and for the HR drawing range. Aerobic Guard does not use FitContributor and
does not create custom FIT developer fields.
